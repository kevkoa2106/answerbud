# AnswerBud

AnswerBud captures multiple-choice questions and compares their answer options with a selected model.

## Language

**Provider profile:** A provider's saved model selection and request preferences. Credentials are separate from the profile.

**Connection test:** A sample question sent to a provider to check whether the selected settings return usable answer data. It is not a model-accuracy evaluation.

**Chosen answer:** The option highlighted from the model's estimates. A chosen answer can still be tentative or incorrect.
_Avoid_: Guaranteed answer, calibrated probability
